配色主题：默认 + 三套新增

每套主题都是完整的 shadcn 变量集（不只是强调色），明暗各一。迷你外壳只用这些变量绘制：标题栏 / 活动栏 / 资源树（选中行与焦点环）/ 标签 / 日志文本 / 按钮 / 输入框 / 菜单。日志着色用新增的扩展令牌 --log-*，文件图标用 --fi-*（见 file-icons.html）。页底附可直接粘贴进 globals.css 的 CSS。

对比度在页内由 oklch → sRGB 实际计算（WCAG 2.x 公式）。文字目标 4.5:1，图形 / 焦点环目标 3:1。默认主题的两处不足（muted-foreground 在 muted 底上 4.34、ring 在白底上 2.59）是 shadcn neutral 原值，本次不改，列为开放问题。

粘贴用 CSS 放在 globals.css 现有强调色块之前

新增主题按 [data-theme='x'] 与 [data-theme='x'].dark 组织（data-theme 与 .dark 都在 <html> 上）；默认主题不设属性。扩展令牌（日志级别、工作区颜色、文件图标颜色）一并给出，并通过 @theme inline 映射为 Tailwind 颜色（如 text-log-error、text-fi-excel、bg-ws-red）。
