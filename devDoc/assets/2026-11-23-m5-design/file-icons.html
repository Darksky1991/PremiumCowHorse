文件图标：按大众认知着色

类别 × 颜色。颜色只分明暗两组（与配色主题无关），每个颜色都对四套主题的背景、侧栏、选中行、卡片底逐一计算了对比度，表中给出最差的一处（图形对比度目标 3:1，WCAG 1.4.11）。图标字形取自 lucide-react 1.73.0（项目已用），表中的字形名都在该版本中存在。

  • A 级（饱和）：有大众共识的品牌色——Word 蓝、Excel 绿、PowerPoint 橙、PDF 红、Outlook 天蓝、黄色文件夹、茶色压缩包。
  • B 级（降饱和）：没有共识、只为区分的类别，色相避开 A 级，饱和度压低。日志是运维最常见的文件，刻意用低饱和青灰，避免整棵树变成一片彩色。
  • 中性：纯文本、未知扩展名、文件链接用主题的 muted-foreground；失效链接用 destructive（与现状一致）。
  • 文件夹额外加 18–30% 同色填充（lucide 的 folder 是单一闭合路径，填充可靠），远看是「黄色文件夹」。其他图标只着色描边：lucide 的 file-* 图标外形被拆成多段路径，填充会出现残缺。
  • 颜色不是唯一线索：同色的类别（csv / Excel、package / archive、audio / video）靠字形区分；PDF 不再沿用 document 的 file-text 字形，改用 file-type。
