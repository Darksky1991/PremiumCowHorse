# 自绘窗口按钮、zip 分发、文档体系

- 日期：2026-11-18
- 里程碑：M0
- 相关提交：（待提交）

## 目标

1. 不使用系统原生窗口按钮（不是遮挡回避），修复按钮遮挡标题栏边框；自行用系统级截屏确认。
2. 不提供安装程序，只提供免安装版本。
3. 文档体系：`doc/`（最新事实依据）、`devDoc/`（开发记录）、`knowledge/`（tips 与错误）、`CLAUDE.md`。
4. 架构文档与实现对齐。

## 做了什么

- 去掉 `titleBarOverlay`，新增 `window.minimize / toggleMaximize / close / getState` 通道与只发给本窗口的 `window.stateChanged` 事件；主进程 `modules/window/`，渲染端 `features/shell/components/window-controls.tsx`、`data/window.ts`。
- 分发：比较三种形式后采用 zip 文件夹版（见下表），移除 NSIS 相关配置。
- 修复外壳布局未撑满窗口（`#root` 缺少 `height: 100%`，Vite 迁移时引入的回归），并加 e2e 断言。
- 系统级截屏脚本 `scripts/os-screenshot.mjs`。
- 架构文档移到 `doc/` 并更新到 v1.3（修正 5.2、6.1、6.2、6.3、12.2、14.2、14.3、16.4 等与实现不一致处，区分目标结构与已实现部分，新增第 20 节）。
- 新增 `devDoc/`、`knowledge/`、`CLAUDE.md`；更新 README。

## 关键决策与理由

| 分发形式            | 实测                                                                                     | 结论               |
| ------------------- | ---------------------------------------------------------------------------------------- | ------------------ |
| NSIS 安装程序       | —                                                                                        | 需求方不需要       |
| portable 单文件 exe | 每次启动 24–31 秒（每次解压约 300MB 到 %TEMP% 并被杀毒软件扫描），强制结束后残留解压目录 | 不采用             |
| zip 文件夹版        | 首次约 15 秒（首次扫描），之后约 1.4 秒                                                  | 采用（需求方确认） |

- 自绘窗口按钮的取舍：Windows 11 悬停最大化按钮时的贴靠布局面板不再出现；双击标题栏最大化 / 还原已验证可用，拖动贴靠、Win+方向键预期可用（未逐一验证）。
- 「优先官方默认」只适用于依赖包、架构与设计；交互行为按实际效果和使用者立场判断（需求方澄清）。Base UI 菜单选中后不关闭的行为，需求方试用后认为可以，暂不调整。

## 验证

- 系统级截屏：改动前确认系统按钮遮挡边框；改动后浅色 / 深色下只有自绘按钮、边框完整、外壳撑满窗口。
- e2e 6 项通过（新增：自绘窗口按钮行为、`navigator.windowControlsOverlay.visible === false`、状态栏贴底）。
- zip 包解压后实际启动两次（14.7 秒 / 1.4 秒）。
- 双击标题栏：Playwright 的鼠标事件不经过系统标题栏逻辑，改用系统级鼠标事件（user32 `SetCursorPos` + `mouse_event`）实测，第一次最大化、第二次还原。
- 未验证：拖动贴靠屏幕边缘、Win+方向键。
