# devDoc：开发过程记录

每个开发任务一份记录，文件名 `YYYY-MM-DD-NN-主题.md`（NN 为当天序号）。记录「发生了什么、为什么」，供日后追溯；
**当前的设计以 [`doc/`](../doc/) 为准**，这里的内容是历史，不随设计变化回改（发现记录本身有误时可以订正并注明）。

## 模板

```markdown
# <主题>

- 日期：YYYY-MM-DD
- 里程碑：M0 / M1 / …
- 相关提交：<hash>（提交后补）

## 目标

## 做了什么

## 关键决策与理由

## 验证

（运行了哪些命令、结果如何；未验证的内容要写明）

## 遗留事项
```
