# 导航、同步与资源树改进（M1-3b）：设计

- 日期：2026-11-19
- 状态：需求方 2026-11-19 提出 10 条改进（见第 1 节原文）；按「原型优先、按控制者建议推进、全部记录」的授权，歧义处由控制者决定，**第 4 节集中列出，待需求方确认**。
- 位置：M1-3 之后、文本预览之前（文本预览的标签同样要进入这套导航）。

## 1. 需求方原文（要点）

1. 地址栏不属于预览窗口，而是和标题栏同级的应用部件。
2. 除了返回上级，添加后退与前进。
3. 路径从工作区开始（可切换）→ 添加的根目录 → 相对路径；选中文件时路径包含文件名。
4. 根目录的「上一级」按逻辑路径回到工作区一级（不是磁盘上的上级）；预览区提供工作区的预览选择界面。
5. 文件树 / 地址栏 / 预览区总是保持同步，展示对应的内容。
6. 文件树与目录预览按文件类型使用不同图标，没有对应图标才用兜底图标。
7. 文件树中目录单击只选中、不展开；点箭头或双击才展开 / 折叠。
8. 根目录可以设置别名，地址栏以别名显示；复制路径 / URI 不受影响，复制真实的绝对路径。
9. 文件树添加「全部折叠」与「定位到选中项」按钮。
10. 文件树添加分组功能，使用每次只能展开一个分组的抽屉形式。

## 2. 方案（控制者决定）

### 2.1 逻辑路径与「位置」

- 每个标签显示一个**位置**（location），三种：
  - **工作区总览**：`pch-workspace:<workspaceId>`（内部 URI，不是文件系统）；
  - **条目内的目录或文件**：真实 URI + 所属条目（folder / file 条目）；
  - **条目之外的目录**（例如经搜索定位或旧数据）：真实 URI，无所属条目，逻辑路径退化为绝对路径。
- 逻辑路径段：`工作区名` ›（分组不出现）› `条目别名（条目标签）` › 相对路径各段 ›（文件时）文件名。
- 「上一级」：相对路径逐级向上；到条目根时再上一级 = 工作区总览；工作区总览没有上一级。不再越过条目根走到磁盘上的上级（替换 M1-3 的行为）。

### 2.2 地址栏（应用部件）

- 位于标题栏正下方、横跨侧栏与内容区的一行（与标题栏同级，不属于任何标签的内容）：`[← 后退] [→ 前进] [↑ 上一级] [⟳ 刷新]  工作区 ▾ › 条目 › 段 › 段 › 文件名`。
- 显示**当前激活标签**的位置；没有标签时显示当前工作区一段。
- 点击路径段 = 在当前标签内导航到该位置；工作区段带下拉，可切换工作区（与标题栏的工作区切换器行为相同）。
- 后退 / 前进 = **按标签的历史**（每个标签独立，浏览器式）；`Alt+←` / `Alt+→`、鼠标侧键；`Alt+↑` / Backspace = 上一级（焦点在目录视图时）。
- 刷新按钮从目录视图移到地址栏（F5 保留）。
- M1-3 目录视图内部的面包屑与「上一级」按钮移除（由地址栏取代）。

### 2.3 工作区总览（预览区）

- 打开 `pch-workspace:<id>` 时，预览区显示该工作区的条目：分组为分节（只读展示，与资源树的分组一致），folder / file 条目为可双击的项（图标、别名、真实路径的悬停提示）。双击 folder 条目 = 在当前标签导航进入；双击 file 条目 = 打开文件。
- 这是应用内置视图（`features/preview` 中的内部视图），不是插件（需要工作区数据，插件拿不到）。

### 2.4 同步（树 ↔ 地址栏 ↔ 预览区）

- **树 → 预览区**：单击节点 = 选中 + 预览打开（复用预览标签；遵守 `explorer.singleClickPreview`）；目录单击**不展开**（需求 7）。键盘 ↑↓ 移动选中后，**200ms 防抖**预览打开（满足「总是同步」，又避免快速移动时频繁加载）——替换 M1-3「↑↓ 不打开」的裁定。
- **预览区 → 树**：激活标签变化、标签内导航（目录视图进入子目录、后退 / 前进、地址栏点段）后，树**选中并滚动到**对应节点（展开所需的祖先）；位置不在树中（工作区总览、条目之外）时树保持原选中不变。
- **地址栏**总是显示激活标签的位置。
- 展开 / 折叠：箭头单击、双击目录、`→` / `←`、Enter（目录）。常驻打开：文件双击 / Enter；目录要常驻时双击标签头（或右键「在新标签页中打开」——如工作量小则做）。

### 2.8 打开方式（需求方 2026-11-20 确认，取代 2.4 中关于预览标签与常驻打开的部分）

浏览器式的统一规则，资源树与目录视图（含工作区总览）都一样：

- **单击（或 Enter）= 在当前标签打开**，记入该标签的历史；没有标签时新建一个标签。
- **中键单击或 Ctrl+单击 = 在新标签打开**（右键菜单「在新标签页中打开」同效）。
- 资源树中**目录的双击 = 展开 / 折叠**（需求 7），箭头同效；文件的双击与单击相同（不另开标签）。
- 目录视图中双击（或 Enter）子目录 / 文件 = 在当前标签打开；「后退」回到目录列表。
- **键盘 ↑↓**：移动选中后防抖（约 200ms）在当前标签打开，并**记入历史**——快速连按只在停留处产生一条历史。
- **取消「预览标签」**（斜体、被复用、转常驻）这一概念：所有标签都是普通标签。设置 `explorer.singleClickPreview` 改为「单击在当前标签打开」（关闭时单击只选中，Enter 打开）。

### 2.5 图标

- 按扩展名映射到图标（lucide，已是依赖；不新增图标库）：文件夹 / 链接 / 文本 / 日志 / 代码 / JSON / 表格（xlsx, csv）/ 文档（docx）/ 演示（pptx）/ PDF / 图片 / 音频 / 视频 / 压缩包 / 可执行 / 配置（ini, conf, yaml）等，未匹配 → 兜底文件图标。
- 映射与 `FileIcon` 组件放在 `@pch/ui`（渲染端与插件都可用）。

### 2.6 别名

- 条目的**标签**即别名（已可重命名）；地址栏与工作区总览、标签标题（条目根时）都显示别名；复制路径 / URI 一律用真实路径（现状不变，确认即可）。

### 2.7 资源树工具栏与分组抽屉

- 资源树标题栏增加：**全部折叠**、**定位到当前项**（把激活标签的位置在树中选中并滚动到，若在树中）。
- **分组抽屉**：工作区根下的分组以抽屉（分节标题）形式显示，**同一时刻只展开一个顶层分组**；展开另一个时其余顶层分组自动收起。未分组的条目显示在所有分组之上，始终可见。分组内的子分组按普通树节点展开（不做互斥）。
- 「添加分组」沿用现有的「新建分组」（M1-2 已有），本次只改展示与互斥行为。

## 3. 不做（记录）

分组出现在逻辑路径中；地址栏直接输入路径；历史跨标签共享或持久化（会话恢复时再定）；多窗口的地址栏。
