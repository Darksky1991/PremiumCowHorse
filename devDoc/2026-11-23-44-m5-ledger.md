## 控制者决定

D1–D15 原文抄自计划「控制者决定」一节（2026-11-23）。

- **D1 最近使用的记录来源**：`tabs-store` 的 `open` / `openHere` / `navigate` 增加可选 `opts.source?: OpenSource`，`OpenSource = 'tree-select' | 'tree-open' | 'palette' | 'overview' | 'address' | 'plugin' | 'history'`；纯函数 `shouldRecordRecent(kind, source)`：`tree-open` / `palette` / `overview` → 文件与目录都记；`plugin` → 只记文件（目录视图逐级进入不记）；`tree-select` / `address` / `history` / 未指定 → 不记。store 不调 IPC：命中时写 `recentSignal: { seq, workspaceId, location }`，由 `features/command-palette` 导出的 `<RecentRecorder />`（挂在 `app.tsx`）订阅并调用 `recent.record`。
- **D2** `recent_items` 每个工作区保留最近 100 条（插入后删除超出部分）；命令面板显示 8 条。
- **D3 工作区排序**：新通道 `workspace.reorder { ids: string[] }`（完整顺序，必须恰好是全部未归档工作区的排列，否则 `IPC_INVALID_INPUT`），按下标写 `sort_order`，一次事务、一次 `workspace.changed`。
- **D4 `workspace.summaries`**：`route<WorkspaceSummary[]>()(z.void())`，`WorkspaceSummary = { id: string; entryCount: number; topEntries: { kind: 'folder' | 'file' | 'group'; label: string; uri: string | null }[] }`；`entryCount` 为该工作区全部条目数，`topEntries` 为根级（`parent_id IS NULL`）按 `sort_order` 前 4 个。只查 `pch.db`。
- **D5 命令面板的过滤**：`cmdk` 用 `shouldFilter={false}`，由 `lib/text-match.ts` 的 `normalizeForMatch` / `matchScore` 统一过滤与排序（与选择器的筛选同一套：NFKC + 小写 + 平假名→片假名；名称前缀 > 名称包含 > 说明包含）。文件组在输入 ≥ 2 个字符时以 150 ms 防抖调用 `search.query`（当前工作区，`limit: 20`）。
- **D6 设置页的数值项**：`Input type="number"` + 单位，按 `settingsSchema.shape[key].safeParse` 校验（与 zod 同源，不重复写 min / max），无效时显示错误、不提交。「恢复默认」= 提交 `DEFAULT_SETTINGS[key]`。
- **D7 关于页的路径**：`AppInfo` 增加 `userDataDir: string`、`logsDir: string`（只用于显示）；新通道 `system.openAppFolder { which: 'logs' | 'userData' }` → `shell.openPath(paths.logs | paths.userData)`。
- **D8 标题栏主题菜单**保留，增加「テーマ」单选组（四套）；明暗选项不变。
- **D9 图标生成**：`scripts/build-icons.mjs` 用 `electron` 运行 `scripts/icons/render.cjs`（离屏 `BrowserWindow` 载入 SVG 的 data URL，`capturePage` 取 PNG），尺寸 `[16,20,24,32,40,48,64,128,256]`，ICO 写出为纯函数 `scripts/icons/ico.mjs` 的 `encodeIco(pngs: { size: number; data: Buffer }[]): Buffer`（PNG 内嵌格式；256 在目录项中写 0）。产物提交进仓库。
- **D10 窗口图标**：`resources/icon.png`（256）经 `paths.ts` 新增 `appIcon` 传给 `BrowserWindow` 的 `icon`；`electron-builder.yml` 加 `win.icon: build/icon.ico`。
- **D11 M2-K3 的「sniff / stat 期间按钮短暂禁用」**不修（可选项，记录推迟）；另两项修。
- **D12 M1-K23**：把 `shadcn` 从 `packages/ui` 的 `dependencies` 移到 `devDependencies`（只在构建时 `@import 'shadcn/tailwind.css'`），以 `pnpm build` 与 `pnpm audit --prod` 验证；若构建失败则撤回并记录。
