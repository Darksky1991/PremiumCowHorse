# M5 完善与发布：实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal：** 把原型推进到可分发的 beta：命令面板与最近使用、设置页、关于页、三套新主题与动效基础、按大众认知着色的文件图标、圆环轮播式工作区选择器（可在设置中换回菜单式）、应用 logo「環」与 exe 图标，以及 beta 前已知缺陷的修正。

**Architecture：** 渲染端新增 feature `command-palette`、`settings`、`about`，工作区选择器放在 `features/workspace`，跨 feature 的组合在 `app/`。快捷键统一由渲染端的命令注册表（`stores/command-store.ts` + `lib/key-context.ts`）分发。主题以 `<html data-theme>` + 每套完整 CSS 变量实现，动效用 `motion`，令牌集中在 `packages/ui/src/lib/motion.ts`。主进程新增 `recent_items` 表（迁移 0008）与 `recent.*` / `workspace.summaries` / `workspace.reorder` / `system.openAppFolder` 通道；UNC 路径的访问范围检查扩展 M4 的 `RemoteAccess`。

**Tech Stack：** Electron 45.3.3、React 19、TanStack Query、zustand、shadcn（Base UI，`base-nova`）、Tailwind v4、`motion` 14.14.0（新依赖，已同意）、`cmdk` 1.1.1（经 shadcn CLI 的 `command` 组件引入，已同意）、node:sqlite + Kysely、zod 4、vitest、Playwright。

**Spec：** [devDoc/2026-11-23-42-m5-design.md](./2026-11-23-42-m5-design.md)；视觉与交互细节以 [设计稿](./assets/2026-11-23-m5-design/design-notes.md)（以下「设计稿 x 节」）及同目录的原型为准。设计文档与设计稿矛盾时以设计文档为准（设计文档对设计稿的改动已逐条写明），并记入台账。

**分支：** `feat/m5-polish`（从 `main` 切出）。每个任务一次提交；合并只在需求方要求时进行。

**台账：** `devDoc/2026-11-23-44-m5-ledger.md`（Task 1 建立）：每个任务的结果、控制者决定、推迟项、未验证项。按 memory「prototype-first」：审查中的 Minor 只记录不修，beta 前统一确认。

## Global Constraints

- 新依赖只有 `motion`（`packages/ui` 的 `dependencies`，精确版本 `14.14.0`）与 `cmdk`（由 shadcn CLI 添加到 `packages/ui`，版本以 CLI 写入为准，台账记录）；其他新依赖一律先问需求方。
- shadcn 组件（`packages/ui/src/components`）由 CLI 生成后不手改样式；`className` 只用于布局。CLI 在含 `.` 的用户目录下失败 → `subst` 临时盘符（`knowledge/libraries.md`）。
- `packages/ui` 不能 import 工作区内其他包（eslint boundaries 无 allow）。
- 渲染端分层：`app → features → providers/data/stores/lib`；feature 之间不互相 import；`stores` / `lib` 只依赖 `shared`。
- IPC 新通道：契约（`packages/shared/src/ipc/contract.ts`，输入 `z.strictObject`）→ 主进程 handler（漏写编译失败）→ 渲染端 `call()`；新事件同时登记 `IpcEvents` 与 `main/core/events.ts`，并在 `bootstrap.ts` 的 `wireEvents` 广播。
- 迁移文件发布后不得修改；改表 = 新迁移 + `infra/db/schema.ts` 类型 + 登记 `migrations/index.ts`。
- i18n：ja / zh-CN / en 同时添加（ja 为类型基准）；用户可见文案不在主进程拼接。
- 文件系统只读原则不变；打开文件夹由主进程按固定路径执行，不接受渲染端传入路径。
- 动效：时长上限 0.3 s；尊重 `appearance.reduceMotion` 与 `prefers-reduced-motion`；动效不得阻塞下一步操作（动画进行中键盘 / 点击照常响应）。
- 设置新增键（`packages/shared/src/settings/schema.ts`）：
  - `appearance.theme: z.enum(['default','aitetsu','washi','matsuba']).default('default')`
  - `appearance.reduceMotion: z.enum(['system','on','off']).default('system')`
  - `workspace.pickerStyle: z.enum(['carousel','menu']).default('carousel')`
  - `workspace.pickerDetail: z.boolean().default(false)`
  - `workspace.pickerView: z.enum(['ring','list']).default('ring')`（选择器头部「リング / リスト」，记住上次选择）
- 工作区颜色键（`packages/shared/src/workspace/colors.ts`）：`WORKSPACE_COLORS = ['blue','teal','green','amber','orange','red','pink','violet','slate'] as const`；`color` 列存键或 null，CSS 令牌 `--ws-<key>`。
- 快捷键：`Ctrl+K` / `Ctrl+Shift+P` 命令面板，`Ctrl+,` 设置，`Alt+W` 工作区选择器（三者加入 `main/modules/web/shortcuts.ts` 的 `APP_SHORTCUTS`），选择器内 `Alt+1–9` 直选。
- 测试范围：每个任务只跑本任务的单元测试文件 + `pnpm typecheck` + `pnpm lint` + `pnpm exec prettier --check .`；动到界面的任务加 `pnpm build` 与相关 e2e。全量只在 Task 17。

## 控制者决定（本计划新增，设计未写或留给实施者的部分）

- **D1 最近使用的记录来源**：`tabs-store` 的 `open` / `openHere` / `navigate` 增加可选 `opts.source?: OpenSource`，`OpenSource = 'tree-select' | 'tree-open' | 'palette' | 'overview' | 'address' | 'plugin' | 'history'`；纯函数 `shouldRecordRecent(kind, source)`：`tree-open` / `palette` / `overview` → 文件与目录都记；`plugin` → 只记文件（目录视图逐级进入不记）；`tree-select` / `address` / `history` / 未指定 → 不记。store 不调 IPC：命中时写 `recentSignal: { seq, workspaceId, location }`，由 `features/command-palette` 导出的 `<RecentRecorder />`（挂在 `app.tsx`）订阅并调用 `recent.record`。
- **D2** `recent_items` 每个工作区保留最近 100 条（插入后删除超出部分）；命令面板显示 8 条。
- **D3 工作区排序**：新通道 `workspace.reorder { ids: string[] }`（完整顺序，必须恰好是全部未归档工作区的排列，否则 `IPC_INVALID_INPUT`），按下标写 `sort_order`，一次事务、一次 `workspace.changed`。
- **D4 `workspace.summaries`**：`route<WorkspaceSummary[]>()(z.void())`，`WorkspaceSummary = { id: string; entryCount: number; topEntries: { kind: 'folder' | 'file' | 'group'; label: string; uri: string | null }[] }`；`entryCount` 为该工作区全部条目数，`topEntries` 为根级（`parent_id IS NULL`）按 `sort_order` 前 4 个。只查 `pch.db`。
- **D5 命令面板的过滤**：`cmdk` 用 `shouldFilter={false}`，由 `lib/text-match.ts` 的 `normalizeForMatch` / `matchScore` 统一过滤与排序（与选择器的筛选同一套：NFKC + 小写 + 平假名→片假名；名称前缀 > 名称包含 > 说明包含）。文件组在输入 ≥ 2 个字符时以 150 ms 防抖调用 `search.query`（当前工作区，`limit: 20`）。
- **D6 设置页的数值项**：`Input type="number"` + 单位，按 `settingsSchema.shape[key].safeParse` 校验（与 zod 同源，不重复写 min / max），无效时显示错误、不提交。「恢复默认」= 提交 `DEFAULT_SETTINGS[key]`。
- **D7 关于页的路径**：`AppInfo` 增加 `userDataDir: string`、`logsDir: string`（只用于显示）；新通道 `system.openAppFolder { which: 'logs' | 'userData' }` → `shell.openPath(paths.logs | paths.userData)`。
- **D8 标题栏主题菜单**保留，增加「テーマ」单选组（四套）；明暗选项不变。
- **D9 图标生成**：`scripts/build-icons.mjs` 用 `electron` 运行 `scripts/icons/render.cjs`（离屏 `BrowserWindow` 载入 SVG 的 data URL，`capturePage` 取 PNG），尺寸 `[16,20,24,32,40,48,64,128,256]`，ICO 写出为纯函数 `scripts/icons/ico.mjs` 的 `encodeIco(pngs: { size: number; data: Buffer }[]): Buffer`（PNG 内嵌格式；256 在目录项中写 0）。产物提交进仓库。
- **D10 窗口图标**：`resources/icon.png`（256）经 `paths.ts` 新增 `appIcon` 传给 `BrowserWindow` 的 `icon`；`electron-builder.yml` 加 `win.icon: build/icon.ico`。
- **D11 M2-K3 的「sniff / stat 期间按钮短暂禁用」**不修（可选项，记录推迟）；另两项修。
- **D12 M1-K23**：把 `shadcn` 从 `packages/ui` 的 `dependencies` 移到 `devDependencies`（只在构建时 `@import 'shadcn/tailwind.css'`），以 `pnpm build` 与 `pnpm audit --prod` 验证；若构建失败则撤回并记录。
- **D13 M2-Q24 用户手势**：Electron 45 的 `setWindowOpenHandler` / `will-navigate` 没有手势字段（已核对 `electron.d.ts`），以「最近一次用户输入」近似：`USER_ACTIVATION_MS = 5_000`，`before-mouse-event` 的 mouseDown 与 `before-input-event` 的 keyDown 更新 `entry.lastInput`；外部链接要求 `now - lastInput <= USER_ACTIVATION_MS`，否则丢弃并记 warn；保留 2 秒节流。
- **D14 M2-K5**：Office 扩展名白名单 `OFFICE_EXTENSIONS` 移到 `packages/shared/src/launcher/types.ts`（与 `plugins/builtin/src/office/index.ts` 共用），`launcher.capabilities` / `launcher.open` 对白名单外的扩展名返回空能力 / `LAUNCH_FAILED`；`web-host.ts` 的 `openExternal` 先经可执行类扩展名确认。
- **D15 M4-K2**：新错误码 `CONN_AUTH_UNSUPPORTED`（不锁定，与 noMethod 同样走 `idle`）。
