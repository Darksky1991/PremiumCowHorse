# M2 预览插件体系：实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在应用内查看 Office（启动面板）、Markdown 与本地 HTML（嵌入浏览器视图），同一文件可切换查看器。

**Architecture:** 渲染端：查看器切换（注册表候选 + 标签位置上的 `viewer`）、地址栏下拉、消息收纳；插件经 `PreviewHost.web` 请求宿主把主进程的 `WebContentsView` 贴到占位元素上。主进程：`modules/web`（每标签一个视图、LRU 8、专用会话分区与 `pch-web` / `pch-asset` 协议、导航判定、按键转发、截图替身）与 `modules/launcher`（PowerShell 检测 verb 并启动 Office）。Markdown 由打包好的浏览器脚本在视图内用 unified + mermaid 渲染。

**Tech Stack:** Electron 45（`WebContentsView`、`session.protocol`）、React 19、zustand、sonner 2.0.8、unified / remark / rehype、mermaid 12、PowerShell、Vitest、Playwright。

**Spec:** [`devDoc/2026-11-20-22-m2-design.md`](./2026-11-20-22-m2-design.md)（定稿）；现状 `doc/` v1.17。

## Global Constraints

- 原型优先（memory「prototype-first」）：只做设计第 2 节「目标」；简报之外只修明显 / 重要的问题，其余记入台账 `devDoc/2026-11-20-24-m2-ledger.md`。测试范围按改动判断；全量在最后一个 Task 由控制者兜底。
- 文件系统原则：只读；协议处理器每个请求 打开 → 读 → 关闭（流结束或中止时关闭）。
- 应用窗口的 `sandbox` / `contextIsolation` / CSP（`apps/desktop/src/renderer/index.html`）不放宽；浏览器视图：`sandbox: true`、`contextIsolation: true`、`nodeIntegration: false`、无 preload、`webSecurity: true`、`devTools: false`、`spellcheck: false`、会话 `persist:pch-web`。
- 下载禁用、DevTools 禁用（需求方决定）。外网允许；本地只读到范围内。
- 常量（设计原值）：视图保活上限 `WEB_VIEW_LIMIT = 8`（每窗口）；范围编号 = `sha256(范围根 URI)` 前 16 个十六进制字符；Markdown 插件 `maxSize = 5 * 1024 * 1024`；消息收纳上限 50；sonner 拖拽阈值用内置 45px；Office 启动超时 15 秒。
- 插件 id：`pch.preview.html`、`pch.preview.markdown`、`pch.preview.office`（html / markdown `priority: 1`）。
- 新依赖只限：`unified`、`remark-parse`、`remark-gfm`、`remark-rehype`、`rehype-slug`、`rehype-stringify`、`mermaid`（需求方已同意；`rehype-raw` 仅在 Task 8 核实确有必要时追加并记录）。不引入 `mime`。
- 分层：新目录先在 `eslint.config.mjs` 登记；主进程模块之间不互相 import；feature 之间不互相 import（地址栏经 store 取得候选）；插件只经 `PreviewHost`。IPC：契约 → handler → `call()`。三语文案同时添加。shadcn 组件不改。
- 不凭记忆写第三方 API：Electron 读 `apps/desktop/node_modules/electron/electron.d.ts`；sonner、unified、mermaid 读各自类型定义。
- 结构变化在同一提交更新 `doc/`；最后一个 Task 升为 v1.18。

## Review Focus

1. HTML 内的相对路径含日文、空格、`%`、`#`、`?`（文件名本身含这些字符）：资源与链接都能正确映射，不被当成查询或锚点。→ Task 5 映射测试。
2. 范围逃逸：`..%2f`、`%2e%2e`、反斜杠、`file:///C:/Windows/...` 绝对链接、UNC 根之上：一律 403 / 阻止并提示，不读到范围外。→ Task 5 处理器测试 + Task 6 导航测试。
3. 浏览器视图焦点中按 F5 / Ctrl+W / Alt+←：应用照常执行，页面收不到这些键。→ Task 6 单元测试 + Task 7 e2e。
4. 应用弹出层（地址栏下拉、确认框、toast）出现在浏览器视图上方时可见可操作；关闭后视图恢复且页面状态未丢失。→ Task 7 e2e（系统截图 + `isVisible`）。
5. 第 9 个网页标签打开：最久未显示的视图被释放，切回时重新加载；显示中的视图不被释放。→ Task 6 单元测试。
