## 2. 待确认的决定清单

### 2.1 M2 实现中的决定（实现记录 25 §4，编号沿用）

- [ ] **Q3 删除设置 `launcher.officeExtensions` / `launcher.officeDefaultAction`** → Office 扩展名固定在插件 manifest，需要可调时连同设置页加回。
- [ ] **Q4 消息收纳** → 收纳被点击收起的消息与自动消失的 `error` / `warning`；`info` / `success` 不收纳；只在内存、最多 50 条。
- [ ] **Q4b Markdown 由应用自带脚本在浏览器视图中渲染** → 为此在视图会话中注册 `pch-asset://`（只提供应用产物）。
- [ ] **Q5 HTML 之间跳转进入标签历史** → 「后退」重新加载上一页（页面内状态与滚动位置不保留）。
- [ ] **Q6 浏览器视图的外部链接白名单比应用多 `http:`**（内网系统）。
- [ ] **Q7 文件变化不自动重新加载页面**（F5 手动）。
- [ ] **Q9 切换查看器时清除当前位置的 viewState；「常にこれで開く」写入 `preview.associations`**。
- [ ] **Q10 浏览器视图的会话持久化**（localStorage 重启后保留，按范围隔离）。
- [ ] **Q11 Office 打开方式表** → 不提供 `OpenAsReadOnly`（本机实为编辑模式）；Excel 经 `/r` 提供「読み取り専用」；「保護ビュー」无条件显示；Word / PowerPoint 无只读。
- [ ] **Q12 「編集」在本机弹出系统「选择应用」对话框** → 系统状态（无 UserChoice），不是本应用缺陷；是否在面板上说明。
- [ ] **Q14 `file:` 绝对链接无反应**（Chromium 在渲染进程拦截，没有「範囲外」提示）→ 是否把范围内的 `file:` 链接改写为 `pch-web:`。
- [ ] **Q15 剪贴板写入放行**（用户手势下，原型的「复制」按钮）；读取与其余权限一律拒绝。
- [ ] **Q16 toast 显示期间页面里敲的键丢失**（视图换成截图时焦点无处可去；应用快捷键照常）。
- [ ] **Q17 PDF 查看器的打印** → 系统打印对话框打开期间主进程阻塞；是否禁用 / 拦截，标题中的应用名「Electron」。
- [ ] **Q18 浏览器视图的焦点规则** → 从资源树 / 应用打开时焦点留在应用；在页面中点链接 / Alt+←→ 时焦点留在新页面（第 26 轮已修复交接）。
- [ ] **Q19 「システムのブラウザーで開く」文案** → 对 PDF / 图片实为关联应用，是否改为「既定のアプリで開く」。
- [ ] **Q20 查看器下拉只有图标**，不显示当前查看器名。
- [ ] **Q21 不同查看器之间（HTML ↔ Markdown）`sessionStorage` 不延续**。
- [ ] **Q22 Markdown 的 CSP 放行 `http:` 图片 / 样式**；`script-src` / `frame-src` 封死。

### 2.2 试用反馈两轮中的决定（控制者判断，待确认）

### 2.3 已确认（供参考）

- **Q1** 依赖 unified / remark / mermaid；**Q8** 禁用 DevTools 与下载（设计阶段）。
- **Q2 / Q13**（2026-11-21）：`pch-web` 范围维持「最外层 folder 条目根」，盘根 / 共享根也不收窄，外网照常放行；不做 realpath 校验（风险已知悉）。
- **第 26 轮**：资源树文件节点的单击 / 双击 / Ctrl 规则；地址框；前置的工作区按钮；工作区一览页与「管理工作区…」；Office 检测每台机器一次。
- **第 28 轮**：工作区图标 GalleryVertical；单击当前段 / 空白处复制路径；卡片式一览（不显示图标、操作直接为按钮、新建也是卡片、各行等高）；地址框中工作区区域不嵌套框、暗色下加强对比。
- **工作方式**：`.claude/` 改为插件安装按原样提交；M2 收尾方式与 M1 相同。

## 4. 已知问题 / 待解决

### 4.1 用户可见

- **K1 `meta refresh` 跳转进入标签历史**，「后退」会再次跳转。出处：25 §6.2 Task 6。
- **K2 Office 面板的小问题**：`uri` 变化时短暂显示上个文件的按钮；「再検出」在启动中未禁用；Word / PowerPoint 也用表格图标；`openWithDefault` 无「起動中」状态。出处：25 §6.2 Task 10。
- **K3 查看器下拉的小问题**：勾选项点击后菜单不关；sniff / stat 期间按钮短暂禁用；快速连点可能覆盖关联写入。出处：25 §6.2 Task 3。
- **K4 Markdown 主题切换整篇重渲染**（图片重读、`details` 状态丢失）；原始 HTML 中的标题没有锚点 id。出处：25 §6.2 Task 8。

### 4.2 内部 / 安全 / 测试

- **K5 `PreviewWebApi.openExternal` 不经可执行类扩展名确认**（目前只对 html / pdf / 图片 / md 调用）；`launcher.open` 主进程不限制扩展名。出处：25 §6.1（最终审查 M8）。
- **K6 `web.attach` 不拒绝 `.` / `..` 段**（读不到范围外，但会保存非规范 URL）；`scopeRoot` 是否属于工作区条目由渲染端保证。出处：25 §6.1。
- **K7 视图生命周期的边角**：未选查看器时换插件视图只隐藏不释放；LRU 每次只淘汰 1 个；`bindDocumentOwner` 依赖 `did-start-navigation`（应用窗口内被阻止的外部导航也会关闭文本文档）；IPC `bounds` / `uri` 无上限。出处：25 §6.2 Task 6 / 7。
- **K8 测试空白**：`PreviewContainer`、Office 面板、`bindWebViewOwner`、`web.ipc` 无单元测试；launcher generation 作废逻辑无测试；开关脚本测试 `< 3000 ms` 在高负载下可能偶发失败。出处：25 §6.2。
- **K9 其余 deferred minor** 见 [实现记录 25 §6.2](./2026-11-20-25-m2.md)（按任务列出，本文不逐条重复）。
