## 1. 目标

把 M0–M4 的原型推进到**可以分发给同事试用的 beta**（设计 42 第 1 节）：补上一直标着「即将推出」的入口（命令面板、设置），让应用有自己的面貌（logo、主题、带颜色的文件图标、更好的工作区切换），并清掉 beta 前已知的小缺陷。对应产品目标第 3 条（工作区隔离案件，切换要快、不出错）、第 4 条（在一个应用里完成工作，键盘可达）、第 7 条（看起来酷）。**非目标**（需求方 2026-11-23）：代码签名（beta 用未签名 zip）、自动更新、多窗口 / 应用内会话、第三方插件、FTP / 远程编辑。**反目标**：动效抢走注意力或让用户等待；工作区切换比以前更容易误点；为了主题弄坏插件或网页视图的可读性。

## 3. 实现概要

详细行为见 doc v1.28 各节，这里只列结构：

- **packages/ui**：`styles/globals.css`（四套主题 × 明暗、强调色、扩展令牌）、`lib/motion.ts`（令牌 + re-export）、`lib/file-icon-map.ts` / `file-icon.tsx`（27 类）、`logo-mark.tsx`、shadcn `command` / `switch`；`shadcn` 改为 devDependency。
- **packages/shared**：设置键 `appearance.theme` / `appearance.reduceMotion` / `workspace.pickerStyle` / `pickerDetail` / `pickerView`；`THEMES`；`workspace/colors.ts`；`recent/{types,policy}.ts`；`layout` 的 `'settings'` / `'about'` 位置与 `OpenSource`；`launcher` 的 `OFFICE_EXTENSIONS` 与 `detectFailed`；`vfs/dot-segment.ts`；错误码 `CONN_AUTH_UNSUPPORTED`；`ConnectionState` 增加 `auth-unsupported`；IPC `workspace.summaries` / `reorder`、`recent.*`、`system.openAppFolder`、事件 `recent.changed`。
- **主进程**：迁移 0008 与 `modules/recent`；`workspace` 的摘要与排序；`system.openAppFolder`；窗口底色按主题、`icon`；Markdown 外壳的主题与脚本注入；网页视图的用户手势与点段检查；launcher 的扩展名白名单；连接的 K2–K4；`vfs/remote-access.ts` 的 UNC 范围。
- **渲染端**：`features/{settings,about,command-palette}`、`features/workspace/picker/`、`stores/command-store.ts`、`lib/{shortcut,key-context,text-match,focus-return,recent-policy}.ts`、`data/recent.ts`；设置写入的乐观更新与按键回滚。
- **工具**：`scripts/build-icons.mjs` / `scripts/icons/{render.cjs,ico.mjs}`（`pnpm icons`）；`e2e/tsconfig.json` / `globals.d.ts`（根 `typecheck` 含 e2e）；新 e2e `about` / `settings` / `palette` / `workspace-picker`。
- **数据**：`pch.db` 迁移 0008（新增表，不改旧表）；`index.db` 不变（`CACHE_VERSION` 仍为 6）。
- **依赖**：`motion` 14.14.0（MIT，连带 `framer-motion` / `motion-dom` / `motion-utils`）、`cmdk` 1.1.1（MIT，连带 4 个 Radix 小包），均经需求方同意。
