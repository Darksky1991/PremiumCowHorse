## 后端（Task 11）

- 查询解析与名称匹配：`packages/shared/src/search/query.ts` 的 `parseQuery`（空白分词，含 `*` / `?` 为 glob，其余为包含）与 `matchesName`（用于主进程处理固定的单个文件条目，与扫描进程 SQL 同一套规则）。类型在 `search/types.ts`。
- 扫描进程：`apps/desktop/src/scanner/search/search.ts`，同步 SQL，只读缓存。
  - 范围：URI 前缀的范围比较（`= root OR (>= prefix AND < prefix 的下一个字典序)`），不用 `LIKE`，无需转义，且可用主键索引；多个范围一条 SQL 用 OR 连接，重叠范围不会重复返回行。
  - 3 个字符（码点）以上的包含词合并为一个 `entries_fts MATCH '"a" AND "b"'`（引号加倍转义）；短词 `LIKE '%..%' ESCAPE '\'`；通配词 `lower(name) GLOB lower(?)`（`[` 转义为 `[[]`，按字面匹配）。
  - 排序：名称以第一个包含词开头者优先，其次名称、目录 URI；第一个词是通配词时不做优先。`total` 计数到 10000 为止；`truncated = total > 返回条数`。
  - `indexedAt` = 范围内目录 `checked_at` 的最小值；`incomplete` = 范围内存在 `listed_at` 为 null 的目录。
  - 命中项：`entryId` 为最长前缀匹配的条目；`relativePath` 为含名称的相对路径，`/` 分隔、已解码；固定的单个文件条目为空字符串。
  - `kind` 过滤：指向目录的符号链接按目录处理。
- 协议：`MainToScanner` 新增 `search`；`cancel` 保留但不使用。
- 取消：扫描进程中的 SQL 无法中途打断。`ScannerClient.search(q, requestId)`：同一 requestId 的新查询、`cancelSearch(requestId)`（由 `vfs.cancel` 触发）以 `FS_CANCELLED` 拒绝旧请求，旧结果到达时被丢弃。
- IPC：`search.query { workspaceId, text, kind, limit?, requestId }`（`main/ipc/search.ipc.ts`）。scopes 来自工作区的 folder 条目；固定的单个文件条目在主进程按名称匹配，排在最前面（`size` / `mtime` 为 0：搜索不访问文件系统，也没有缓存的元数据；`kind=directory` 时不匹配；与扫描结果重复的 URI 只保留固定条目）；读取 `explorer.showHiddenFiles`；扫描进程不可用时 `INDEX_UNAVAILABLE` 原样抛出。
- 已知差异：FTS5 trigram 的大小写折叠覆盖 Unicode，`LIKE` 与 `lower()` 只折叠 ASCII，而主进程的 `matchesName` 用 `toLowerCase()`；只影响非 ASCII 大小写（如 `É` / `é`）在短词、通配词与固定文件条目之间的一致性，设计也声明不做全角半角归一化，暂不处理。

## 性能（node:sqlite，内存库，本机一次实测）

100 个目录 × 1000 条 = 10 万条名称，范围为全部。结果上限 1000 条，`total` 上限 10000。测试断言宽松上限 2000ms。

| 查询                                               | 耗时 |
| -------------------------------------------------- | ---- |
| 3 字以上单词，约 1.25 万命中（`total` 封顶 10000） | 21ms |
| 3 字以上单词，少量命中                             | 2ms  |
| 3 字以上两个词                                     | 2ms  |
| 短词（2 字符），无命中                             | 20ms |
| 短词（2 字符），大量命中                           | 34ms |
| 通配词 `alpha_5*.dat`                              | 39ms |
| 通配词 + 3 字以上词                                | 20ms |

仅为内存库中的数据；磁盘库、冷缓存、真实目录结构下的数字未验证。
